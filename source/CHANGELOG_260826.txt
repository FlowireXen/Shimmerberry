# Challenger Approaching
... I hope you'll be here when they arrive ;)

## Vanilla Changes
- Fixed a bug with Jokers that save the player from Death; Jokers now properly save the Player if they run out of cards
- "Flower Pot" Joker: X4 Mult if poker hand contains 4 different suits

## Technical Changes
- Added Artist credits to the bottom of most cards/objects
- Updated Jokers with changing textures (Textures don't flicker on load)
- Replaced "Repairable" pool with "Durability" pool
- Lots of tiny code reworks for the sake of stability (Mostly omitted from these Patch-Notes)

## Eden System
- Winning a run rewards an "Eden Token", some Jokers may reward additional Tokens
- Added "Eden Token"-Consumable: On use removes an "Eden Token" to spawn a random Joker
- - "Eden Token"-Consumable only spawns if the player has "Eden Tokens"
- Eden Tokens can be disabled in the Mod-Config!
