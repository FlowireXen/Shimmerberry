== Bugfixes ==

<blockquote>Normally, {{vj|Mr. Bones}} cannot save the player if they run out of cards in their deck. However, if the player has two Mr. Bones, running out of cards puts the game in a glitched state where it ends the round every frame, with very strange results. [...] Using this glitch, it is possible to progress past ante 39. If done on a boss round, it ups the ante constantly.</blockquote>

'''[[Shimmerberry]]''' fixes a bug that stops Mr. Bones from saving the player if they run out of cards.<br>
Additionally, if the player dies with two Mr. Bones, the game does not constantly up the Ante anymore.<br>
This Bugfix affects all Mods that have a Player-Saving Joker.
